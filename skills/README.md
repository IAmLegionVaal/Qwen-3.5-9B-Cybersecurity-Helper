# Downloadable Agent Skills

This folder contains **32 portable Agent Skills** for a local Bionic/Qwen cybersecurity helper: **28 original skills**, including the ten core starters and eighteen additional security/pentest workflows, plus **4 pinned MIT-licensed upstream Microsoft security skills**.

Start with [the skill-selection guide](../docs/15-CYBERSECURITY-SKILL-PATHS.md), then download the repository ZIP via GitHub **Code → Download ZIP**, and inspect/import one SKILL.md through **Bionic Settings → Skills**.

No proprietary local skill bundles, API credentials, access tokens, offensive binaries, malware or exploit packs are included. The original workstation's exact installed files remain outside this public package.

**Third-party attribution:** [Microsoft security skill provenance and license](../third-party/microsoft-security-skills/PROVENANCE.md). Original third-party files retain their original licenses. They have not been exhaustively security-audited; review before granting privileged tools.

For detailed installation, system prompt, hardware compatibility and security risks, see [START HERE](../docs/00-START-HERE.md).
